# public

브라우저가 그대로 받아 가는 파일을 둡니다. 주소는 `/파일이름`입니다.

## hero.jpg — 첫 화면 배경

`src/app/page.tsx`가 `/hero.jpg`를 배경으로 깝니다.

**이 폴더에 `hero.jpg`라는 이름으로 넣으면 바로 적용됩니다.** 바꿀 때도 같은
이름으로 덮어쓰면 됩니다.

- **파일이 없어도 화면은 멀쩡히 뜹니다.** 배경색이 먼저 칠해져 있습니다
- 가로로 넓은 사진이 맞습니다. 화면 전체를 덮고 가운데를 기준으로 잘립니다
- 밝은 사진이든 어두운 사진이든 글자가 읽히도록 **어두운 겹**을 하나 깔아
  두었습니다. 그래도 글자가 걸리는 자리(왼쪽 위~가운데)는 비교적 단순한
  사진이 낫습니다
- 너무 크면 첫 화면이 늦게 뜹니다. **1MB 안쪽**을 권합니다
