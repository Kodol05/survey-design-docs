# public

브라우저가 그대로 받아 가는 파일을 둡니다. 주소는 `/파일이름`입니다.

## hero.jpg — 첫 화면 배경

`src/app/page.tsx`가 `/hero.jpg`를 화면 가득 깝니다. 같은 이름으로 덮어쓰면 바뀝니다.
가로로 넓고 밝은 사진, 사람은 오른쪽, 왼쪽은 비어 있어야 합니다(제목·버튼 자리).
300KB 안쪽을 권합니다.
