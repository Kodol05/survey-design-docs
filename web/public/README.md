# public

브라우저가 그대로 받아 가는 파일을 둡니다. 주소는 `/파일이름`입니다.

## hero.jpg — 첫 화면 배경

`src/app/page.tsx`가 `/hero.jpg`를 배경으로 깝니다.

**이 폴더에 `hero.jpg`라는 이름으로 넣으면 바로 적용됩니다.** 바꿀 때도 같은
이름으로 덮어쓰면 됩니다.

- 가로로 넓은 사진이 맞습니다. 화면 전체를 덮고 **가로 72% 지점**을 기준으로
  잘립니다 — 사람이 오른쪽에 있는 지금 사진에 맞춘 값입니다
- **왼쪽 절반은 비어 있어야 합니다.** 거기에 제목·버튼이 얹힙니다
- **밝은 사진을 전제로 합니다.** 지금은 왼쪽에서만 살짝 밝히는 겹을 깔고
  검은 글씨를 씁니다. 어두운 사진으로 바꾸시면 글자색도 같이 바꿔야 합니다
  (`src/app/page.tsx`의 첫 화면 부분)
- 너무 크면 첫 화면이 늦게 뜹니다. **300KB 안쪽**을 권합니다.
  받은 원본이 1.7MB였는데 가로 2400px · JPEG 82%로 줄여 **144KB**가 됐습니다
