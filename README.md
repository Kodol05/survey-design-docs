## 다이어그램 검증

문서를 고친 뒤 다이어그램이 깨지지 않았는지 확인합니다.

```bash
cd tools && npm install   # 최초 1회
node tools/mermaid-lint.mjs docs
```

파싱 오류뿐 아니라 GitHub에서 깨질 문법과 한글 관련 함정도 함께 잡습니다. 규칙은 `04-mermaid-rules.md`에 있습니다.
