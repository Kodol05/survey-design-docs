# 밖에서 볼 수 있게 올리기

대표님이 회사 밖에서 여실 수 있게 하는 방법입니다. **이 PC가 그대로 서버**가 됩니다.

## 한 줄로

```bash
cd web
npm run share
```

창에 주소가 크게 찍힙니다. 그 주소를 대표님께 보내드리면 됩니다.

---

## 먼저 아셔야 할 것 둘

**① 이 창을 닫으면 끊깁니다.** PC가 꺼져도 마찬가지입니다. 대표님이 밤에 열어보시려는데 사무실 PC가 꺼져 있으면 안 열립니다. 사내 서버로 옮기기 전까지는 그렇습니다.

**② 주소가 매번 바뀝니다.** 무료 터널은 열 때마다 새 주소를 줍니다. 껐다 켜면 대표님께 새 주소를 다시 보내드려야 합니다.

주소를 고정하려면 도메인이 하나 있어야 합니다(연 1~2만 원). 그때는 `cloudflared tunnel create`로 이름 있는 터널을 만듭니다.

---

## 무엇이 도는가

`npm run share`가 넷을 순서대로 합니다.

| | 하는 일 | 안 되면 |
|---|---|---|
| 1 | DB가 떠 있는지 확인 | `npm run db:up` 을 먼저 |
| 2 | 완성본이 있는지 확인 | 코드를 고쳤다면 `npm run build` 를 먼저 |
| 3 | 앱을 3000번에 띄움 | 3000번을 쓰는 것이 있으면 그것부터 끄기 |
| 4 | Cloudflare 터널을 붙임 | `cloudflared` 위치가 다르면 `CLOUDFLARED` 환경변수로 |

손으로 넷을 띄우면 그중 하나를 잊습니다. 실제로 시험하다 **옛 서버를 붙잡고 한참 헤맸습니다** (2026-08-26).

### cloudflared 가 안 잡힐 때

`winget install Cloudflare.cloudflared` 로 깔면 `C:\Program Files (x86)\cloudflared\` 에 들어가는데 **PATH 에는 안 들어갑니다.** 그래서 `cloudflared --version` 이 안 먹습니다. 스크립트는 그 경로를 직접 봅니다.

## 밖에서 무엇을 할 수 있나

올린 상태에서 실제로 두들겨 본 결과입니다 (2026-08-26).

| | |
|---|---|
| 대표님·직원이 보는 화면 | 첫 화면 · 로그인 · 가입 (응답 0.3초대) |
| 남의 결과·명단·분석 | **전부 로그인으로 튕김** |
| 백업·CSV 내려받기 | **307 로 차단** |
| 남의 설문에 답 써넣기 | 세션 **주인까지** 확인함 |
| 관리자 되기 | 가입은 사원 고정. 관리자는 사전 지정만 |
| 비밀번호 찍어보기 | 계정당 관리자 5회·사원 10회 → 15분 잠금 |

### ⚠️ 열려 있는 것 하나

**가입에 자격 검사가 없습니다.** 이름 + 아무 `010` 번호면 계정이 생기고 곧장 설문에 들어갑니다. 그 답이 평균·상관·α·사내 위치에 그대로 섞입니다.

지금은 **인원 200명 상한**으로 폭주만 막아 뒀습니다 (`web/src/lib/auth/signupCap.ts`). 제대로 된 방어가 아닙니다 — 200명 안쪽으로 들어오는 것은 못 막습니다.

계속 밖에 열어 두실 거라면 둘 중 하나를 하셔야 합니다.

- **명단으로 막기** — `Roster` 표에 있는 번호만 가입되게. 그게 제대로 된 방어입니다.
- **Cloudflare Access** — 앱 앞단에서 이메일 인증을 요구합니다. 50명까지 무료입니다. 관리자 화면에만 걸면 통과가 필요한 사람은 둘뿐입니다.

## 끝낼 때

창에서 `Ctrl+C` 를 두 번 누릅니다. 주소는 그 자리에서 죽습니다 (확인함 — 닫은 뒤 접속하면 530).

DB 는 계속 떠 있습니다. 내리시려면 `npm run db:down`.
