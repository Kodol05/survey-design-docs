# 7차원 성향 설문 — MVP 구현 계획 v2

작성일 2026-08-23 · `2026-08-20-seven-dimension-survey-mvp.md`를 대체합니다

**Goal:** 사내 구성원이 웹에서 성향 설문과 직무능력 설문을 한 번에 응시하고, 제출 즉시 본인 결과를 확인하며, 관리자는 성향과 직무능력의 관계를 화면에서 확인·분석할 수 있는 시스템을 만든다.

**Architecture:** Next.js 16 App Router 단일 애플리케이션. 채점은 DB·네트워크에 의존하지 않는 순수 함수로 격리해 단위 테스트로 검증한다. 문항은 코드가 아닌 YAML 파일로 관리하고 seed 스크립트로 DB에 주입한다. 인증은 `AuthProvider` 인터페이스 뒤에 격리한다.

**Tech Stack:** Next.js 16 (App Router) · TypeScript · PostgreSQL 16 · Prisma · Tailwind CSS · Recharts · Vitest · Docker Compose

**Spec:**
- `docs/00-design-notes.md` — 의사결정 근거, 데이터 모델, 척도 구조
- `docs/01-features-ux.md` — 화면·상호작용·기능 명세
- `docs/07-job-ability.md` — 직무능력 3가지 상세
- `docs/11-ui-guide.md` — 색·부품·차트 규격, 화면별 매핑

## G. 분석 화면 ★ 핵심

**Task 20이 먼저입니다.** 21~25가 전부 그 부품을 씁니다.

### Task 20 — 차트 부품

`11` §3. 레이더 · 상관 표 · 순위 막대 · 산점도.

| 부품 | 놓치면 안 되는 것 |
|---|---|
| 상관 표 | **발산 색** (파랑↔회색↔빨강). 단색이면 강한 음의 상관이 "낮은 값"으로 보임 |
| 상관 표 | 칸 안에 숫자 직접 표기 + **칸마다 n 배지** |
| 순위 막대 | **상위 8개까지만** |
| 산점도 | 점 50개를 그대로. 겹치면 2px 바탕색 테두리 |

### Task 21 — 관련도 표 화면

**연구 값 / 우리 회사 데이터를 탭으로 분리** (F-46). 하나는 고정이고 하나는 사람이 늘 때마다 바뀌므로 절대 섞지 않습니다.

### Task 22 — 직무능력 ↔ 성향 순위 (양방향)

능력을 누르면 관련 성향 순위, 성향을 누르면 그 축 상위자의 직무능력 (F-47). 종합 직무능력 순위도 여기.

> 세부 항목 28 × 직무능력 3 = **84개 상관**. 관계가 없어도 네댓 개는 우연히 높게 나옵니다. **다중비교 경고를 상시 표시**하고 상위 8개에서 자릅니다.

### Task 23 — 성향 × 직무능력 산점도

추세선 + n 배지 (F-45). F-35(성향 축끼리, 추세선 없음)와 다른 화면입니다.

### Task 24 — 계산식 + 대조 화면

성향으로 직무능력을 예측하는 회귀식을 사내 데이터로 만들고, 실제 값과 얼마나 어긋나는지 봅니다 (`10`).

| 반드시 | 이유 |
|---|---|
| **LOOCV** (한 명 빼고 49명으로 식을 만들어 뺀 사람을 맞춤, 50회 반복) | 그냥 맞추면 외운 걸 다시 묻는 셈이라 반드시 잘 맞습니다 |
| 예측 vs 실제를 **산점도**로 | 45도 선에서 벗어난 정도가 바로 보임. 오차 숫자 하나로는 누가 어긋났는지 모름 |
| **과적합 경고 배지** | "이 회사 데이터로 만든 식이라 실제 오차는 더 큽니다" |
| 세부 항목(28개)으로는 식을 만들지 않음 | 변수가 사람 수의 절반을 넘습니다. 7축까지만 |

> 이 화면이 답하는 것은 **설문 안에서 앞뒤가 맞는가**입니다. 성향 문항과 직무능력 문항을 같은 사람이 이어서 답하므로, 잘 맞는다고 실제와 맞는 것은 아닙니다. 그건 Task 31이 답합니다.

### Task 25 — 척도 신뢰도 화면

척도별 Cronbach's α (F-23). **α가 .60 아래인 척도는 그 상관을 볼 필요가 없습니다.** 이 화면이 없으면 못 만들어진 척도의 상관을 열심히 해석하게 됩니다.

직무능력은 능력당 3문항이라 α가 낮게 나올 가능성이 있습니다. 값을 보고 문항을 늘릴지 판단합니다 (`07`).
